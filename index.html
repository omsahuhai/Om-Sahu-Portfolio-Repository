Easy Manager

Multi-business petrol-pump management SaaS for tracking meter readings, fuel rates, expenses, and dealer profitability.

Problem Solved: Retail petrol pump stations handle multi-nozzle shifts, fluctuating daily fuel tariffs, cash/credit ledgers, and operator payouts manually on paper. Easy Manager unifies meter readings, fuel rates, expenses, sales, and dealer margin calculations into automated, real-time financial reporting.
What I Built:
  • Built type-safe operational workflows using Next.js Server Actions with strict Zod validation.
  • Implemented centralized PostgreSQL reporting views for automated daily fuel sales and dealer profit summaries.
  • Designed multi-tenant data isolation using Supabase Auth with Row-Level Security (RLS) scoped by business_id.
  • Engineered meter continuity validation logic preventing odometer logging errors and gap discrepancies.
Technologies: Next.js · TypeScript · Supabase PostgreSQL · Server Actions · Zod · Tailwind CSS
