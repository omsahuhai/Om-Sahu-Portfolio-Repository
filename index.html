Easy Manager

A multi-business retail management SaaS built for Indian petrol-pump operators.

Problem Solved: Retail petrol pump stations handle multi-nozzle shifts, fluctuating daily fuel tariffs, cash/credit ledgers, and operator payouts manually on paper. Easy Manager unifies meter readings, fuel rates, expenses, sales, and dealer margin calculations into automated, real-time financial reporting.
Engineering Highlights:
  • Built type-safe operational workflows using Next.js Server Actions with strict Zod validation.
  • Implemented centralized PostgreSQL reporting views for automated daily fuel sales and dealer margin calculations.
  • Designed multi-tenant data isolation using Supabase Auth with Row-Level Security (RLS) scoped by business_id.
  • Engineered meter validation logic preventing odometer continuity breaks and operator data entry errors.
Tech Stack: Next.js · TypeScript · Supabase PostgreSQL · Server Actions · Zod · Tailwind CSS

College Papers — AI Exam Prep

An intelligent exam-preparation platform converting previous-year question papers into targeted revision roadmaps.

Problem Solved: University students often struggle to identify key exam topics from disorganized historical papers. College Papers analyzes past PDFs to extract syllabus modules, topic recurring frequencies, and tailored study schedules.
Engineering Highlights:
  • Integrated Google Gemini API to analyze PDF exam papers, extracting syllabus units and question distribution.
  • Engineered a situation-aware study strategy engine that adapts topic priorities based on time remaining before exams.
  • Implemented serverless document parsing pipelines for rapid multi-page question paper ingestion.
Tech Stack: Next.js 14 · React · Google Gemini API · Supabase · Tailwind CSS
